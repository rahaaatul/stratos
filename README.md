- This repository stores **Magisk** modules for [MMRL](https://github.com/DerGoogler/MMRL) and [MRepo](https://github.com/MRepoApp/MRepo.git).

## Add to MMRL or MRepo 

```url
https://rahaaatul.github.io/stratos
```

## Add to MMRL-CLI

```shell
mmrl repo add "https://rahaaatul.github.io/stratos/json/modules.json"
```
