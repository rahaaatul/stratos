#### It's advised to clean install if you're facing notification delay issues.
### GMS Services
- Fixed `unfreeze_category()` not guarding ROM-disabled services.
- `pm disable`/`pm enable` and `jobscheduler cancel` now loop over every user profile, not just user 0.
- GMS/GSF/Firebase whitelisted from Deep Doze by default; Firebase's `ComponentDiscoveryService` moved to a notification-critical `keep` category.
- Added "Enable all" / "Disable all" buttons, only touching categories not already in the target state.
### Deep Doze
- Added a Minimum tier below Moderate: gentler timeouts, `frequent` standby bucket, no `WAKE_LOCK` or ther severe restrictions, no sensor disable, no wakelock killer. 
- Restrictions now follow lock state, not screen state, with a screen-wakefulness fallback for devices with no lockscreen.
- Screen/lock detection is now event-driven with polling fallback.
- Default dialer, SMS app, keyboard, and home launcher detected live instead of a static list: whitelist trimmed accordingly. Kept what's still static.
- Screen monitor start/stop uses an atomic lock instead of a bare PID check.
- Fixed the wakelock killer's 5-minute countdown counting loop iterations instead of elapsed time.
- Fixed motion sensors staying disabled after a Maximum monitor is stopped and replaced mid-session.
- Fixed `am get-standby-bucket` comparison using numeric codes instead of names.
- Wakelock killer now skips alarm/notification/push-tagged wakelocks.
### Screen Off Optimization
- Same lock-state, event-driven, and atomic-lock rework as Deep Doze.
- Idle polling backs off instead of fixed-interval.
- Fixed Mobile Data sometimes force-restored when the user had it off.
- Fixed connections staying disabled forever with Restore on Unlock off.
- Fixed scheduled RAM clean blocking the monitor loop.
- Fixed sensors/Panel LPM not re-disabling after an AOD pulse restored them mid-session.
- Monitor daemon consolidated with Deep Doze's into `scripts/monitor_common.sh`.
- Wi-Fi/BT/data disable re-evaluated continuously while locked instead of a one-shot check.
- Added call detection: skips/restores Wi-Fi/data during an active call. Bluetooth restores if media starts playing.
### WebUI
- Added Multitasking Profile (Performance/Balanced/Power Saving).
- Fixed backup restore truncating values containing `=`.
- Fixed blur disable reporting success on KSU/APatch when the prop couldn't actually be set.
- `setPref()` validates every value before it reaches `user_prefs`, closing a root-context injection surface.
- Fixed `device_config put/delete` output leaking into JSON responses.
- Added `webroot/config.json` and `icon.png` for WebUI-X/MMRL home screen shortcuts.
- Backup delete/rename now shell-escaped (`app.js` built raw `rm`/`mv` commands with no escaping).
- Removed dead `list_frozen`/`list_gms` dispatch calling undefined functions.
- App Doze's picker now chunks `getPackagesInfo()` calls like the other pickers already did.
- Confirmed Frosty's field names and `ksu://icon/` scheme match the real host API: hosts missing the API entirely just fall back to raw names, which is already correct behavior.
- Added a Bug Report option to the WebUI menu (Language, Import/Export, Bug Report, About): generates a device/config/log dump to `Frosty/Logs`, no personal info (accounts, IMEI, phone number, Wi-Fi, location) included. `bug_report.yml` template updated to point here instead of a manual Termux command.

- Fixed the USAP pool toggle being a silent no-op; switched to `device_config`.
- Fixed Multitasking Profile compounding its multiplier on repeated switches instead of reverting to baseline first.
- De-duplicated Multitasking Profile revert into a shared function.
- ZRAM algorithm revert reports `"partial"` when `swapoff` times out.
### Kernel Tweaks

- Fixed `sched_features` not being restorable by revert.
